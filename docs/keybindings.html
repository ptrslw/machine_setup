Rules that make the rest predictable
1h←  j↓  k↑  l→ — same direction in tmux panes, Neovim windows, and motions.
2lowercase acts, UPPERCASE resizes / stronger variant (tmux h focus vs H resize).
3Splits: | vertical bar → side‑by‑side, - → stacked.
4Move tmux panes → hit the prefix first. Inside Neovim, C-h/j/k/l moves an editor split, not a pane.
5Keys feel broken in Neovim? You're in the wrong mode — hit Esc.
6GUI IDEs (Cursor / VS Code / CLion) are exempt — use their own defaults.
