# packages/agent-skills.txt — skill packs this machine wants, agent-neutral.
#
# One pin per line: owner/repo@sha (full 40-char hex). Skill packs steer agents
# that run shell and edit trees — never float on main. Bump the SHA deliberately
# after reviewing the upstream diff.
#
# This file is the declaration of intent; installers/agent-skills.sh translates
# it into whatever mechanism each installed agent actually supports:
#
#   Claude Code   marketplace plugin        user-global  (claude/settings.json)
#   Codex         codex plugin marketplace  user-global  (repo only; CLI has no pin)
#   Gemini CLI    gemini skills install     user-global  (repo only; CLI has no pin)
#   Cursor        .cursor/skills/           per-project  (agent-skills-sync @ SHA)
#   OpenCode      project skills/           per-project  (agent-skills-sync @ SHA)
#
# The local cache (~/.cache/agent-skills/) is always at the pinned SHA. Claude /
# Codex / Gemini marketplace installs follow those tools' own resolution until
# they grow pin support — see docs/agents.md.
